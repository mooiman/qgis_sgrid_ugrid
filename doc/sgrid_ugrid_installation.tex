\section{Installation}
\phantom{mooiman}\vspace{-\baselineskip}
\begin{action}
\item Copy the file \file{\sugrid.dll} to the \Cpp plugin directory of QGIS.
In my installation it is:\newline
\dir{c:\textbackslash OSGeo4W64\textbackslash apps\textbackslash qgis\textbackslash plugins\textbackslash sgrid\_ugrid.dll}.

\item Install the user manual on the program files directory\newline \dir{c:\textbackslash Program Files\textbackslash Mooiman\textbackslash sgrid\_ugrid\textbackslash doc}
\begin{itemize}
	\item sgrid\_ugrid\_um.pdf
\end{itemize}

\item Install the icons on the program files directory\newline \dir{c:\textbackslash Program Files\textbackslash Mooiman\textbackslash sgrid\_ugrid\textbackslash icons}
\begin{itemize}
    \item file\_open.png
    \item map\_output.png
    \item plotcfts.png
    \item remote\_olv.png
    \item \ldots
\end{itemize}
\item Install the program \plotcfts on the program files directory\newline \dir{c:\textbackslash Program Files\textbackslash Mooiman\textbackslash plotcfts}
\end{action}

\paragraph*{Some notes}
\phantom{mooiman}\vspace{-\baselineskip}
\begin{itemize}
\item The \sugrid.dll need the following dll's, so they should be in the \%PATH\%-environment variable:
\begin{itemize}
    \item qt6core.dll
    \item qt6gui.dll
    \item qt6widgets.dll
\end{itemize}

\item Next dll's are probably already placed in the \%PATH\%-environment variable when installing QGIS:
\begin{itemize}
    \item qgis\_core.dll
    \item qgis\_gui.dll
\end{itemize}
\end{itemize}
